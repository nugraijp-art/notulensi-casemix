🏥 Sistem Notulensi Digital Casemix RSUD Dr. Iskak

Aplikasi berbasis web untuk pencatatan notulensi rapat, daftar hadir, dan pengarsipan digital yang dirancang khusus untuk Instalasi Casemix RSUD Dr. Iskak Tulungagung.

✨ Fitur Utama

Input Notulensi & Daftar Hadir: Form yang mudah digunakan dengan penghitung jumlah peserta otomatis.

AI Smart Refine: Menggunakan Google Gemini AI untuk merapikan catatan rapat menjadi poin-poin profesional secara otomatis.

Cloud Archiving: Penyimpanan data aman menggunakan Firebase Firestore.

Google Sheets Sync: Sinkronisasi data otomatis ke Google Spreadsheet via Google Apps Script.

Standar Akreditasi: Format cetak (Print-ready) yang sudah disesuaikan dengan kop surat dan tata letak resmi rumah sakit.

Auto-Draft: Fitur penyimpanan draf otomatis agar data tidak hilang saat browser tertutup.

🚀 Teknologi yang Digunakan

Frontend: React.js dengan Tailwind CSS untuk desain responsif.

Icons: Lucide React.

Database: Firebase Auth & Firestore.

Integrasi: Google Apps Script (Web App).

AI Engine: Google Gemini Pro API.

🛠️ Cara Penggunaan di GitHub

Buat repositori baru di GitHub.

Salin kode utama dari notulensi_casemix.jsx ke file proyek Anda.

Pastikan konfigurasi Firebase (__firebase_config) sudah terisi dengan benar.

Hubungkan WEB_APP_URL dengan URL Google Apps Script yang sudah di-deploy.

Internal Use - RSUD Dr. Iskak Tulungagung.

Dikembangkan untuk mendukung digitalisasi administrasi rumah sakit yang efisien dan akurat.
